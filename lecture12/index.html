尽管 ChatGPT或者Deepseek 可以编写完整的代码，但是要与集成开发环境（Integrated Development Environment，IDE）无缝对按，使用ChatGPT 就不太方便了，尤其是在生成片段代码时，如补全一个函数的定义、补全某个语句等，在这种情况下，使用GitHub Copilot 是一个非常好的选择。当然，最好是将 ChatGPT 与 GitHub Copilot一起使用：使用 ChatGPT 生成一个完整的解决方案，并使用 GitHub Copilot 对这个解决方案进行微调。

提示词的编写技巧

  • 给AI工具指定一个角色：第一句“你是pandas专家”
  • 交代背景：给出文件的路径，以及文件中变量的名称，行列信息
  • 说明问题：解决什么问题，必要时说明用什么方法解决，以及指定输出内容，形式和格式
  • 必要时给出示例：帮助AI工具理解意图

注意事项

  • 提倡用短句，用专用词指定对象，避免使用“它”和“前面”等词
  • 明确指定输出内容，可以是全部数据，也可以是一部分
  • 指定输出的数据格式，输出文件的路径和名称，甚至编码

目前几款主流AI编程工具

    人在编程，AI安静地在旁边提示 + 补代码
  • Copilot：可能需要魔法，价格较低，主要在 VSCode 中使用。国内平替：CodeGeeX
  • Copilot 也在持续进化，已经开始加入 Agent 功能
    • 人和 AI 协同编程，AI 深度参与工程开发
  • Cursor: 需要魔法，价格中等偏贵，独立IDE。国内平替：Trae.ai国内版
    • AI 可自主完成开发任务，人负责描述需求与审核结果
  • Claude Code (命令行)/Codex: 需要魔法，价格较高，对命令行与工程环境要求较高

推荐学生党使用：

  • VSCode + Copilot/CodeGeeX + 国内免费大模型
  • Trae.ai 国内版（更适合新手）
  • 不差钱不会命令行：Cursor
  • 不差钱且熟悉命令行：Claude Code
